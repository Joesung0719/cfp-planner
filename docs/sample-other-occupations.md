# 範例：企業主、自營作業者、軍公教、農民（50 歲）

開始頁的「企業主範例／自營範例／軍公教範例／農民範例」按鈕載入下列數字。勞工範例見 `docs/sample-labor-50.md`。
載入前會先把所有欄位還原成頁面原始預設值，所以不會殘留上一個範例的數字。

**標示說明**：`法`＝法令或官方公告數字，已核對；`官`＝官方文件逐項核對（簡明表）；`用`＝**使用者提供**，未經官方統計驗證；`設`＝示意假設（使用者未提供，為了讓頁面能算出完整結果而設）；`待`＝待確認。
這些範例不是統計平均，也不代表任何一位真實客戶。

## 使用時請注意
- 「家庭財務健診」不含所得稅與保費（保費欄位範例未填），所以儲蓄率看起來偏高。
- 傳承完整度是看「已安排」的項目，範例只填了保單受益人，所以分數很低是正常的，用來示範頁面如何提醒。
- 年終工作獎金 1.5 個月在考績法中找不到依據，若取得正式規定文件再改標「官」。
